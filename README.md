## Power BI Dashboard

## Project Overview

This project presents an interactive Power BI dashboard for analyzing NexusGoods e-commerce performance from 2016 to 2018.

The dashboard provides insights into revenue, orders, delivery performance, customer ratings, product categories and payment methods.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modelling
- Microsoft PowerPoint

## Key Metrics

- Total Revenue
- Total Orders
- Delayed Orders
- Delay Rate
- Average Customer Rating
- Revenue Growth
- Payment Method Distribution

## Dashboard Features

- Revenue and order KPI cards
- Monthly revenue trends
- Product-category performance
- On-time and delayed-order analysis
- Customer-rating analysis
- Regional sales comparison
- Payment-method analysis
- Interactive filters and slicers

## Key Insights

- Revenue increased significantly between 2016 and 2018.
- Health and beauty was the highest-revenue category.
- Approximately 7.9% of orders experienced delivery delays.
- The average customer rating was approximately 4.07 out of 5.
- Some product categories recorded higher delays and lower ratings.
